# Tripleten web_project_around_pt

Around The U.S. é um projeto desenvolvido durante o bootcamp de desenvolvimento web da TripleTen, uma página de perfil interativa onde o usuário pode editar suas informações pessoais e adicionar cartões com fotos de lugares, com toda a interface construída de forma orientada a objetos em JavaScript puro. O projeto permite editar nome e descrição do perfil, adicionar novos cartões com foto e título, curtir ou descurtir cartões, remover cartões, visualizar a imagem ampliada ao clicar em um cartão, validar formulários em tempo real e fechar os pop-ups pelo botão de fechar, por clique na área externa ou pela tecla Esc. Foi construído com JavaScript ES6+ usando classes e módulos ES, HTML5 semântico e CSS3 com Flexbox/Grid e a metodologia BEM, aplicando conceitos de programação orientada a objetos como herança e encapsulamento. A arquitetura segue uma estrutura de classes desacopladas, cada uma com uma responsabilidade única: a classe Card cria e gerencia o elemento visual de cada cartão, cuidando de curtir, deletar e abrir a imagem; a Section renderiza uma lista de elementos em um container da página; a Popup é a classe base para pop-ups e controla abertura, fechamento e os eventos comuns de Esc, clique externo e botão de fechar; a PopupWithImage estende Popup para exibir a imagem ampliada com legenda; a PopupWithForm estende Popup para os pop-ups com formulário, cuidando da coleta de dados, do envio e do reset; a UserInfo gerencia a leitura e a atualização das informações do perfil na tela; e a FormValidator cuida da validação dos formulários em tempo real. O arquivo index.js fica responsável apenas por instanciar essas classes e conectar os eventos entre elas.
